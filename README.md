# Pacha Plate Perfect

Crée un site web complet, moderne, premium et responsive pour le restaurant :

LE PACHA RESTAURANT

Localisation : Angré 8e Tranche, Feu du SICOMEX, Abidjan, Côte d’Ivoire

Téléphone / WhatsApp : +225 07 07 17 05 14

Service : restauration sur place, à emporter et livraison.

IMPORTANT :

Je vais ajouter dans le projet une image de référence du restaurant LE PACHA.

Utilise cette image comme référence pour comprendre l’identité visuelle, les couleurs, le positionnement et l’ambiance de la marque.

Ne reproduis pas simplement l’affiche sous forme de page web.

Construis un véritable site de restaurant professionnel autour de cette identité.

==================================================

1. OBJECTIF

==================================================

Le site doit permettre au client de :

- découvrir LE PACHA ;

- consulter le menu ;

- consulter le menu du jour ;

- voir les prix ;

- choisir des plats ;

- ajouter plusieurs plats à un panier ;

- modifier les quantités ;

- choisir livraison ou retrait ;

- renseigner son adresse de livraison ;

- transmettre sa commande au restaurant via WhatsApp ;

- appeler directement le restaurant ;

- réserver une table ;

- localiser le restaurant.

Le parcours principal doit être :

ACCUEIL → MENU → PANIER → INFORMATIONS CLIENT → COMMANDE WHATSAPP

Le site doit être pensé en priorité pour les utilisateurs mobiles.

==================================================

2. IDENTITÉ VISUELLE

==================================================

Reprendre l’univers graphique de LE PACHA :

- crème / blanc cassé ;

- brun chocolat ;

- orange cuivré ;

- touches dorées ;

- blanc ;

- ambiance chaleureuse et premium.

Le résultat doit évoquer :

restaurant africain contemporain,

cuisine ivoirienne,

produits frais,

élégance,

générosité,

qualité premium.

Utiliser une typographie serif élégante pour les grands titres et une typographie sans-serif moderne pour les textes.

Éviter :

- design SaaS ;

- cartes trop techniques ;

- interface froide ;

- couleurs flashy ;

- surcharge visuelle.

==================================================

7. PANIER

==================================================

Créer un véritable panier côté frontend.

Quand un client clique sur « Ajouter » :

le produit est ajouté au panier.

Le panier doit permettre :

- augmenter quantité ;

- diminuer quantité ;

- supprimer un article ;

- vider le panier ;

- afficher le nombre d'articles ;

- calculer le sous-total.

Afficher une icône panier dans le header avec badge du nombre d’articles.

Sur mobile, rendre le panier très facile à utiliser.

==================================================

ne pas demander d’adresse.
